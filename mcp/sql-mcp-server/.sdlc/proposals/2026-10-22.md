## P3 — Defects found are read from the gate's own Verdict line
Recurrence: The defect count measures nothing
Target: `skills/sdlc/scripts/sdlc_lint.py`: `count_findings()`, and the `defects_found` field in `record_gate()`; `skills/sdlc/assets/reference/metrics.md`, the `defects_found` sentence
Change:
- Count the blockers and gaps on the artifact's last
  `Verdict: … (N blockers[, M gaps]…)` line.
- The critique skill already requires that line ("Verdict: fail (1 blocker,
  1 gap, 0 nits)", critique `SKILL.md`), and the code review writes it too.
- When there is no such line, fall back to the old heading count, now at any `#` depth.
- On a pass, count only when that last Verdict line is itself a `pass`. That is

In this repository the router transcribed critiques as bullets instead. The
Verdict line is the one thing every gate here wrote in the prescribed form, so
counting it holds whichever way the findings themselves are formatted.
