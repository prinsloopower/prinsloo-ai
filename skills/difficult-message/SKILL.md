# Difficult message

A hard message has competing goals: get the outcome, keep the relationship, protect the user's position. Offer **variants** that resolve that tension differently, so the user chooses a strategy and not a tone.

## Gather
- What happened, and the thread or message being answered if there is one.
- The outcome the user wants, and the outcome they most need to avoid.
- Who the recipient is to the user: manager, peer, report, customer, vendor.
- Channel: email, chat or text. Length follows the channel.
- `business-context.md`, if one is in the working folder, project or attachments, for voice.

Ask once, in one message, if the wanted outcome is unclear. A draft without it is a guess.

## Steps
1. Name the tension in one line: "You want X, and you also want Y."
2. Write two or three variants that would lead to different outcomes. Typical strategies:
   - **Hold the line**: state the position and the reason, offer nothing.
   - **Offer a trade**: concede something cheap to win what matters.
   - **Ask first**: surface the other side's constraint before taking a position.
   - **Escalate cleanly**: bring in the decision-maker, with the recipient told first.
   - **Rip the bandage**: the news in the first sentence, support after.
3. In every variant: the point in the first sentence, facts as observed with dates, one request, and a next step the recipient can take.
4. Label each variant in two to four words, then one line each for **Protects** and **Costs**.
5. Recommend one, with the reason tied to the outcome the user asked for.

## Done when
- Swapping the labels between variants would be noticeable: each one takes a different path.
- Each variant states what it protects and what it costs.
- No variant asserts a fact, date or commitment that is not in the inputs.
- Delivered as drafts for the user to choose from and send.
