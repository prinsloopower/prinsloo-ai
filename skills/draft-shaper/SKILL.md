# Draft shaper

Find the **spine**: the one sentence the piece exists to deliver. Every part of the source either hangs from the spine or goes on the cut list. The source itself is read, never edited.

## Gather
- The raw material: notes, fragments, a transcript, bullet lists, an old draft. All of it.
- Where the piece will be published and roughly how long it should run.
- `creator-context.md`, if one is in the working folder, project or attachments: it sets voice, audience, platforms, brand and tools.

## Steps
1. Read everything. Number each distinct idea, story, example and fact in the source so that nothing is lost track of.
2. Write the spine in one sentence. If two candidates compete, show both and ask which piece this is.
3. Choose the form that suits the spine: how-to, argument, story, list, comparison or case study. Say which and why in one line.
4. Order the sections by dependency: the reader meets each idea after the ones it relies on.
5. Assign every numbered item to a section or to the cut list. Each item appears in exactly one place.
6. Write the draft in the author's voice, using their phrasing wherever it exists in the source.
7. Where the piece needs something the source lacks, write a marker such as `[gap: example of a failed launch]`. Facts, quotes, numbers and anecdotes come only from the source, and so does anything the author thought, felt or intended: a connecting sentence may link two ideas, and may not report a motive the notes never gave.
8. Offer three titles and write the opening paragraph last, once the spine has held up.
9. Save the draft as a new file beside the source. Append the cut list and the gaps.

## Shape
```
# <Title>
Spine: <one sentence>
Form: <which, and why>

<Draft>

---
Title options
Gaps: what the piece still needs from the author
Cut: source items left out, with the reason
```

## Done when
- Every numbered source item is in the draft or on the cut list.
- Every fact, quote, number, story and stated motive in the draft can be found in the source.
- The source file is unchanged, and the draft is a separate file.
- Each section supports the spine, and the spine is stated at the top.
