# Brand kit

Start from **positioning**: who this is for and what it stands for. Every visual choice afterwards is justified by a line in the positioning, which is what separates an identity from decoration.

## Gather
- What the brand is, who it is for, and what it should feel like.
- Names, taglines and any existing assets to keep.
- Brands the user admires and brands they want to stand apart from.
- Where it will live: channel art, thumbnails, site, print, product.
- `creator-context.md`, if one is in the working folder, project or attachments: it sets voice, audience, platforms, brand and tools.

Ask once, in one message, for the audience and three words for the feel if they are missing.

## Steps
1. Write the positioning: audience, what the brand does for them, three personality words, and one "we are X, not Y" line.
2. Develop three **logo directions** that differ in concept: for example a wordmark, a monogram and a symbol. Give each a one-line rationale tied to the positioning, and draw each as original SVG.
3. Build the palette: one primary, one or two secondary, three neutrals, each with a hex value and a role. Compute contrast ratios in code and list the text and background pairs that reach 4.5 to 1.
4. Choose typography: a heading face and a body face that are free to use, with fallbacks, sizes and weights.
5. Write the usage rules: clear space, minimum size, backgrounds the logo may sit on, and the misuses to avoid, shown as examples.
6. Show the identity applied: avatar, banner, thumbnail template, one social post.
7. Add voice in brief: three traits, each with a line that sounds like the brand and one that does not.
8. Assemble the guidelines board as a single page: positioning, logos, palette, type, usage, applications. Build it with the session's document or page tools.
9. Deliver the board, the logo files, and the palette and type as copyable values.

Logo drafts are starting points for a designer or for refinement. Checking a name or mark against existing trademarks is the user's step before using it publicly, and the board says so.

## Done when
- The three logo directions are different ideas, each with its rationale.
- Every color has a hex value and a role, and every text pairing shown passes 4.5 to 1.
- Both typefaces are named with their license.
- Each visual choice points back to a line in the positioning.
- The board opens and every section is filled.
